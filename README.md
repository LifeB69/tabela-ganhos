# Tabela de Ganhos

Tabela e calculadora de quanto se paga por hora trabalhada no mês (8 a 15 dias, 1 a 6 h/dia, R$ 10, 12 e 15 por hora).

Abra o link do GitHub Pages no celular e toque em "Adicionar à tela inicial" para usar como app, inclusive sem internet.

Tudo roda no navegador: nenhum dado é enviado para lugar nenhum.
